# Wishlist на Go

Минималистичное веб-приложение для создания личных вишлистов, просмотра вишлистов друзей и подписки на пользователей. Проект написан на Go без внешних веб-фреймворков: сервер, маршруты, шаблоны, сессии и локальное хранилище реализованы средствами стандартной библиотеки.

## Идея проекта

Пользователь может вести свой список желаний, добавлять товары с ценой, ссылкой и приоритетом, а также смотреть открытые списки других пользователей. Благодаря подпискам можно быстро возвращаться к вишлистам друзей.

Проект подходит для защиты, потому что в нём есть полный цикл веб-приложения: авторизация, работа с данными, шаблоны, формы, обработка HTTP-запросов, локальная база, валидация и клиентский интерфейс.

## Функциональность

- регистрация и вход в аккаунт;
- выход из аккаунта;
- создание личного вишлиста;
- добавление желания с названием, ценой, приоритетом, картинкой и ссылкой;
- удаление только своих желаний;
- публичная страница пользователя вида `/u/username`;
- просмотр вишлистов других пользователей;
- страница всех пользователей `/users`;
- подписка и отписка от пользователей;
- блок «Подписки» на главной странице;
- минималистичный адаптивный интерфейс;
- кеширование статических файлов;
- локальное хранение данных в `data/wishlist-db.json`.

## Технологии

| Часть | Используется |
|---|---|
| Backend | Go, `net/http` |
| HTML-шаблоны | `html/template` |
| Хранилище | JSON-файл `data/wishlist-db.json` |
| Авторизация | cookie-сессии |
| Пароли | PBKDF2-HMAC-SHA256 + соль |
| Frontend | HTML, CSS, JavaScript |
| Стили | минималистичный адаптивный дизайн |

## Запуск

### Вариант 1: запуск через Go

```bash
go run .
```

После запуска открыть в браузере:

```text
http://127.0.0.1:8080
```

### Вариант 2: запуск готового бинарника на Linux или WSL

```bash
./wishlist
```

### Вариант 3: запуск на Windows

```powershell
.\wishlist.exe
```

Или запустить файл:

```text
run_windows.bat
```

## Сборка

### Linux / macOS

```bash
go build -o wishlist .
./wishlist
```

### Windows

```powershell
go build -o wishlist.exe .
.\wishlist.exe
```

### Сборка Windows-версии из Linux / WSL

```bash
GOOS=windows GOARCH=amd64 go build -o wishlist.exe .
```

## Запуск на другом порту

Linux / macOS:

```bash
PORT=3000 ./wishlist
```

Windows PowerShell:

```powershell
$env:PORT=3000; .\wishlist.exe
```

После этого открыть:

```text
http://127.0.0.1:3000
```

## Маршруты

| Маршрут | Метод | Назначение |
|---|---:|---|
| `/` | GET | Личный вишлист текущего пользователя |
| `/login` | GET / POST | Страница входа и обработка входа |
| `/register` | GET / POST | Страница регистрации и создание аккаунта |
| `/logout` | POST | Выход из аккаунта |
| `/add` | POST | Добавление желания |
| `/delete` | POST | Удаление желания |
| `/users` | GET | Страница всех пользователей |
| `/u/{username}` | GET | Публичный вишлист пользователя |
| `/follow` | POST | Подписаться на пользователя |
| `/unfollow` | POST | Отписаться от пользователя |
| `/static/*` | GET | CSS и JavaScript |

## База данных

Проект использует локальный JSON-файл:

```text
data/wishlist-db.json
```

В базе хранятся:

- пользователи;
- сессии;
- желания;
- подписки.

Упрощённая структура:

```json
{
  "next_user_id": 1,
  "next_item_id": 1,
  "users": [],
  "sessions": [],
  "items": [],
  "follows": []
}
```

При изменении данных файл сохраняется атомарно: сначала создаётся временный файл, затем он заменяет основной. Это снижает риск повреждения базы при записи.

## Безопасность

В проекте реализованы базовые меры защиты:

- пароли не хранятся открытым текстом;
- для паролей используется PBKDF2-HMAC-SHA256 с солью;
- сравнение хеша выполняется через constant-time compare;
- сессия хранится в HttpOnly cookie;
- cookie использует `SameSite=Lax`;
- пользователь может удалять только свои желания;
- нельзя подписаться на самого себя;
- никнейм валидируется регулярным выражением: латиница, цифры и `_`, длина от 3 до 24 символов;
- цена проверяется на корректный формат и не может быть отрицательной.

## Сценарий демонстрации

1. Запустить сервер командой `./wishlist` или `go run .`.
2. Открыть `http://127.0.0.1:8080`.
3. Зарегистрировать первого пользователя.
4. Добавить несколько желаний.
5. Выйти и зарегистрировать второго пользователя.
6. Перейти на `/users`.
7. Открыть публичный профиль первого пользователя.
8. Подписаться на него.
9. Показать, что подписка появилась в блоке «Подписки».
10. Объяснить, что данные сохраняются в `data/wishlist-db.json` и не исчезают после перезапуска.

## Частые проблемы

### Браузер показывает `ERR_CONNECTION_REFUSED`

Сервер не запущен. Нужно открыть терминал в папке проекта и выполнить:

```bash
./wishlist
```

или:

```bash
go run .
```

Терминал нельзя закрывать, пока сайт используется.

### Порт 8080 занят

Запустите проект на другом порту:

```bash
PORT=3000 ./wishlist или lsof -ti:8080 | xargs kill -9
```

### Данные не отображаются после переноса проекта

Проверьте, что рядом с бинарником есть папки:

```text
data/
templates/
static/
```

Без них сервер не сможет корректно загрузить базу, HTML-шаблоны и стили.
